# TopBearing — оновлення каталогу 2026-09-22

Це оновлення переводить каталог на керовані з адмін-панелі категорії/підкатегорії та структуровані характеристики товарів.

## Що змінилося

- Категорії більше не задаються жорстко в Python. Їх можна додавати, редагувати, вимикати й видаляти в **Адмін-панель → Категорії**.
- Категорія може мати батьківську категорію. Активні категорії з прапорцем «Показувати в каталозі» автоматично потрапляють у меню.
- Системний `product_type` визначає набір характеристик: `bearings`, `belts`, `seals`, `lubricants`, `accessories`, `generic`.
- Підкатегорія успадковує `product_type` від батьківської категорії.
- `Сальники та манжети` залишаються однією категорією без підкатегорій.
- Для ременів створюються: `Клинові`, `Зубчасті`, `Поліклинові`, `Багаторучейні`.
- Для підшипників створюються широкі конструктивні підкатегорії. Кількість рядів, тіло кочення та серії `NU/NJ/NUP/...` зберігаються окремими характеристиками, а не дублюються в дереві категорій.
- У картках каталогу замість маркування показується розмір.
- Якщо бренду немає, поле бренду не створюється. Якщо вказано лише країну виробництва (наприклад, Китай), клієнт бачить тільки країну.
- Брендовий фільтр формується тільки з брендів, які реально є у товарах вибраної категорії.
- Фільтри не надсилають запит після кожного символу. Дані застосовуються кнопкою `Застосувати`.
- Для сальників фільтр працює по `d / D / B`; матеріал залишається характеристикою, але не фільтром.
- Профілі ременів нормалізуються (`В` → `B`, `6 РК` → `6PK`).
- Пагінація компактна; доступні 24 / 50 / 100 / 200 товарів на сторінку.
- Головна сторінка: рекомендовані товари → популярні за продажами → актуальні як резервний варіант.
- Сторінка товару: `Схожі за параметрами` та `З цим товаром часто купують`.
- Якщо фото немає, для підшипника/ременя/сальника генерується нейтральне SVG-схематичне зображення. Воно не видається за реальне фото і підписане «не в масштабі».
- В адмінці товарів є пошук, сортування, фільтрація та згортаний блок фільтрів.

## Початкова структура

### Підшипники

- Кулькові радіальні
- Самовстановлювальні кулькові
- Радіально-упорні кулькові
- Упорні кулькові
- Роликові
- Сферичні роликові
- Циліндричні роликові
- Конічні роликові
- Голчасті
- Упорні роликові
- Корпусні підшипники та вузли

Приклад: `дворядний сферичний роликовий` зберігається як підкатегорія `Сферичні роликові`, `rows=2`, `rolling_element=roller`, `construction=сферичний`.

Приклад: `однорядний циліндричний роликовий NU` — `Циліндричні роликові`, `rows=1`, `series_type=NU`.

### Пасові ремені

- Клинові
- Зубчасті
- Поліклинові
- Багаторучейні

Профіль (`A`, `B`, `SPZ`, `6PK` тощо) є характеристикою товару, а не окремою категорією.

### Сальники та манжети

Одна категорія без підкатегорій. Основні пошукові параметри: внутрішній діаметр, зовнішній діаметр, ширина.

## Безпечне застосування на робочій БД

1. Зупиніть застосунок або переведіть магазин у технічне вікно.
2. Зробіть резервну копію PostgreSQL (pgAdmin або `pg_dump`).
3. Активуйте `.venv`.
4. Переконайтеся, що `.env` містить правильний `DATABASE_URL`.
5. Виконайте:

```bat
alembic current
alembic upgrade head
alembic current
```

Після оновлення `alembic current` має показати `20260922_01 (head)`.

## Очищення неправильного каталогу

Спочатку лише перегляд:

```bat
python scripts\clear_catalog.py
```

Якщо кількість товарів правильна і backup уже створено:

```bat
python scripts\clear_catalog.py --yes
```

Скрипт:
- видаляє товари, зображення та технічні специфікації;
- не видаляє категорії;
- не видаляє користувачів, налаштування або замовлення;
- в історичних `OrderItem` залишає snapshot назви/SKU/ціни, а `product_id` робить `NULL`.

За потреби після очищення можна прибрати невикористані бренди:

```bat
python scripts\clear_catalog.py --yes --prune-brands
```

## Новий CSV-імпорт

Шаблон заголовків: `docs/topbearing_import_template.csv`.

Запуск:

```bat
python scripts\import_products_csv.py path\to\products.csv
```

За замовчуванням імпортер **не пропускає неповні технічні дані**:
- підшипник: потрібні `inner_diameter_mm`, `outer_diameter_mm`, `width_mm`;
- ремінь: потрібні `profile`, `length_mm`;
- сальник: потрібні `seal_inner_diameter_mm`, `seal_outer_diameter_mm`, `seal_width_mm`.

Це зроблено, щоб не повторити старий імпорт із товарами без розмірів.

Старий аварійний режим для legacy-файлів існує, але для нового каталогу його не рекомендується використовувати:

```bat
python scripts\import_products_csv.py products.csv --allow-incomplete-specs
```

Категорію краще створити в адмінці заздалегідь та передавати її `code` у колонці `category`. Імпортер може створити категорію тільки якщо CSV явно містить `category_name` та `product_type`.
