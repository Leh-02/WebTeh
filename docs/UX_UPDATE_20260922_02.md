# UX update 2026-09-22 (revision 2)

This revision contains storefront-only UX changes and does **not** require a new Alembic migration.

## Changes

- Desktop `Каталог` menu rebuilt as a stable two-pane hierarchy. There is no hover gap between the trigger and the dropdown; moving the pointer from a root category to its subcategories keeps the menu open.
- Desktop catalogue filters now have their own vertical scroll area. `Застосувати / Скинути` remain sticky at the bottom of the filter panel.
- Home-page category cards are equal height and use technical schematic SVG illustrations instead of descriptions/subcategory text.
- `Полтава` is shown explicitly on the contacts page and in the footer.
- Removed the helper text about Cyrillic characters from the belt profile filter. Input normalization is still supported internally.
- Brand options are scoped to the selected category. Changing category refreshes the brand list without submitting the catalogue form. After filters are applied, the brand list is also derived only from products matching the current catalogue scope.

## Files changed

- `app/main.py`
- `templates/base.html`
- `templates/home.html`
- `templates/catalog.html`
- `templates/contacts.html`
- `static/css/app.css`
- `static/js/app.js`

No database schema changes are included in this revision.
